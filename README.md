# 🛠️ Sistema Web de Préstamo de Equipos

Sistema desarrollado para la gestión y control de inventario y préstamos de equipos tecnológicos, optimizando el flujo entre encargados y estudiantes.

## 🚀 Características Principales
- **Roles de Usuario:** 
  - **Encargado (Admin):** Control total del sistema, gestión de equipos (CRUD), administración de usuarios y control general de préstamos.
  - **Estudiante:** Acceso al catálogo de equipos disponibles y visualización de sus propios préstamos en modo de solo lectura.
- **Gestión de Inventario:** Registro, actualización y control de estados de equipos (Disponible, Prestado, Mantenimiento).
- **Control de Préstamos:** Registro de solicitudes y devoluciones con validaciones en tiempo real.

## 💻 Tecnologías Utilizadas
- **Backend:** PHP / Laravel 11
- **Frontend:** Blade Templates, Tailwind CSS, Vite
- **Base de Datos:** MySQL / XAMPP
